#   auth     anon = shared anonymous cookie jar, user = shared logged-in jar (runs in file order)
#   expect   page marker(s) that must appear in the FINAL body; '-' = none. Regex (grep -E), several joined with '~' (all must match).
#            body classes `cl-<controller>` prove we landed on the right page (a redirect to login/basket/start fails).
#   {PLACEHOLDERS} come from the shop DB (see smoke.sh); {STOKEN}/{MD5} come from the previous page of the same jar
#   Checks on every URL regardless of this file: status, error markers, leftover template syntax, PHP warnings,
#   missing translations, truncated page, new ERROR/CRITICAL log lines; on user lines and POSTs also no `alert alert-danger` box.
#   POST lines form the checkout/compare/wishlist sequences and must stay in this order.
